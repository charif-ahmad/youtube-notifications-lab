# Lab Notebook

This notebook is the working record of how the lab is built and what each experiment teaches. The top-level README introduces the project to visitors; this folder keeps the step-by-step setup, hypotheses, run conditions, evidence, and findings.

Keep tracked notes useful to another reader: use placeholders for machine-specific values, record commands and measured results, and never commit passwords, tokens, private keys, or other credentials. Personal connection details belong in `local/`, which is ignored by Git on this machine.

## Contents

- [`setup/ssh-and-server-baseline.md`](setup/ssh-and-server-baseline.md): SSH access, GitHub deploy-key setup, and the initial server inventory.
- [`experiments/stage-01-synchronous.md`](experiments/stage-01-synchronous.md): the first experiment plan and evidence checklist.
- [`templates/experiment-log.md`](templates/experiment-log.md): a reusable record for future test runs.

## Experiment record format

For each run, capture the question, hypothesis, software/configuration versions, workload, start and end conditions, results, and evidence. Compare like-for-like runs and label unmeasured items as pending rather than filling gaps with estimates.
